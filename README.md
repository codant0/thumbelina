# Thumbelina

AI-powered application built with FastAPI and LangGraph.

## Quick Start

```bash
# Install dependencies
pip install -e ".[dev]"

# Run the application
thumbelina

# Run tests
pytest
```

## Project Structure

```
thumbelina/
├── src/thumbelina/    # Application source code
│   ├── __init__.py
│   ├── main.py        # FastAPI entry point
│   └── config.py      # Configuration management
├── tests/             # Test suite
├── docs/              # Documentation
└── pyproject.toml     # Project metadata and dependencies
```
