# Thumbelina - 个人AI代理助手设计文档

## 概述

Thumbelina是一个受OpenClaw和Hermes Agent启发的个人AI代理助手，专注于日常任务自动化、开发辅助、信息检索和个人知识管理的最小功能集合。

## 与现有项目的差异点

### 与OpenClaw相比
- **更简单的架构**：单进程 vs OpenClaw的多仓库生态系统
- **Python技术栈**：vs OpenClaw的TypeScript基础
- **内置学习循环**：技能提取和改进（OpenClaw需要插件）
- **本地优先**：数据隐私优先 vs OpenClaw的云集成方式

### 与Hermes Agent相比
- **Web优先界面**：vs Hermes Agent的TUI优先方式
- **更简单的插件系统**：基础插件支持 vs Hermes Agent的完整生态系统
- **聚焦功能集**：仅核心功能 vs Hermes Agent的全面工具集
- **LangGraph基础**：vs Hermes Agent的自定义代理循环

## 核心需求

1. **使用场景**：日常任务自动化、开发助手、信息检索、个人知识管理
2. **技术栈**：Python
3. **模型支持**：模型无关（支持多种LLM提供商）
4. **用户界面**：Web优先（FastAPI + React/Vue）
5. **数据存储**：本地优先（SQLite + 向量数据库）
6. **插件系统**：简单插件机制
7. **调度功能**：自然语言调度
8. **记忆系统**：学习循环（技能提取和改进）
9. **子代理系统**：隔离的子代理并行处理

### 分层架构

```
┌─────────────────────────────────────┐
│         Web界面 (FastAPI)            │
├─────────────────────────────────────┤
│         API网关层                    │
├─────────────────────────────────────┤
│    代理核心 (LangGraph)              │
│  ┌─────────────────────────────┐    │
│  │  记忆系统 (学习循环)         │    │
│  │  子代理管理器                │    │
│  │  调度器 (自然语言调度)       │    │
│  │  插件管理器                  │    │
│  └─────────────────────────────┘    │
├─────────────────────────────────────┤
│         提供商抽象层                 │
│    (OpenAI, Anthropic, Ollama...)    │
├─────────────────────────────────────┤
│         存储层 (SQLite)              │
└─────────────────────────────────────┘
```

### 核心组件

1. **代理核心**：基于LangGraph的状态机，处理用户请求
2. **记忆系统**：对话历史 + 技能提取 + 用户建模
3. **子代理管理器**：管理隔离的子代理实例
4. **调度器**：解析自然语言时间表达式
5. **插件管理器**：加载和管理插件

### 数据流

用户请求 → Web API → 代理核心 → [记忆/工具/LLM] → 响应

## 详细组件设计

### 1. 学习循环系统

#### 学习流程
```
用户交互 → 任务执行 → 结果评估 → 技能提取 → 技能存储
    ↑                                           ↓
    └───────────── 技能应用 ←────────────────────┘
```

#### 核心组件

**记忆管理器**
- 对话历史存储（SQLite）
- 向量索引（用于语义搜索）
- 会话摘要生成

**技能提取器**
- 分析成功任务的执行过程
- 提取可复用的操作模式
- 生成技能描述和触发条件

**技能存储**
- 技能元数据存储
- 技能版本管理
- 技能评估指标

**用户建模器**
- 用户偏好学习
- 工作模式识别
- 个性化推荐

#### 学习触发机制
- 任务成功完成后自动触发学习
- 定期回顾历史对话，提取新模式
- 用户反馈（显式评分）

#### 技能应用
- 语义匹配：根据当前任务查找相关技能
- 技能组合：多个简单技能组合成复杂技能
- 技能改进：根据执行结果优化技能

### 2. 子代理系统

#### 子代理架构
```
┌─────────────────────────────────────┐
│         主代理 (LangGraph)           │
├─────────────────────────────────────┤
│         子代理管理器                 │
│  ┌─────────────────────────────┐    │
│  │  子代理池                    │    │
│  │  ┌─────┐ ┌─────┐ ┌─────┐   │    │
│  │  │ SA1 │ │ SA2 │ │ SA3 │   │    │
│  │  └─────┘ └─────┘ └─────┘   │    │
│  └─────────────────────────────┘    │
├─────────────────────────────────────┤
│         通信层                       │
│    (消息队列 / 共享内存)             │
└─────────────────────────────────────┘
```

#### 子代理类型

**任务代理**
- 执行特定任务（文件处理、数据分析等）
- 独立上下文，不污染主对话
- 完成后返回结果

**监控代理**
- 后台监控任务（文件变化、定时检查等）
- 持续运行，按条件触发
- 可以主动通知主代理

**工作代理**
- 处理长时间运行的任务
- 支持进度汇报
- 可以被取消或暂停

#### 通信机制
- **消息队列**：异步消息传递
- **共享内存**：关键状态共享
- **事件系统**：子代理事件通知

#### 生命周期管理
- 创建：根据任务需求动态创建
- 执行：隔离环境运行
- 监控：跟踪状态和资源使用
- 清理：完成后释放资源

### 4. 调度系统和插件系统

#### 自然语言调度系统

**调度流程**
```
自然语言输入 → 时间解析器 → Cron表达式 → 任务队列 → 定时执行
```

**核心组件**
- **时间解析器**：理解"每天早上9点"、"每周五下午"等表达式
- **任务队列**：管理待执行任务
- **执行器**：在指定时间触发任务
- **通知系统**：任务执行结果通知

**调度类型**
- 一次性任务："明天下午3点提醒我开会"
- 重复任务："每天早上9点检查邮件"
- 条件任务："当文件更新时通知我"

#### 插件系统

**插件架构**
```
┌─────────────────────────────────────┐
│         插件管理器                   │
│  ┌─────────────────────────────┐    │
│  │  插件注册表                  │    │
│  │  插件加载器                  │    │
│  │  插件沙箱                    │    │
│  └─────────────────────────────┘    │
├─────────────────────────────────────┤
│         插件接口                     │
│  ┌─────────────────────────────┐    │
│  │  工具                        │    │
│  │  技能                        │    │
│  │  频道                        │    │
│  │  提供商                      │    │
│  └─────────────────────────────┘    │
└─────────────────────────────────────┘
```

**插件类型**
- **工具插件**：添加新工具（如特定API调用）
- **技能插件**：添加新技能（如特定领域知识）
- **频道插件**：添加新消息平台（如Telegram、钉钉）
- **提供商插件**：添加新LLM提供商

**插件接口**
```python
class Plugin(ABC):
    name: str
    version: str
    description: str
    
    @abstractmethod
    def register(self, manager: PluginManager) -> None:
        pass
    
    @abstractmethod
    def get_tools(self) -> list[Tool]:
        pass
```

**冲突解决机制**
1. **命名空间**：插件使用`plugin_name.provider_name`格式
2. **版本控制**：插件可以指定兼容的系统版本
3. **依赖声明**：插件可以声明依赖其他插件或内置功能
4. **回退机制**：插件失败时自动回退到内置功能

- 本地数据优先（不上传到云端）
- 数据匿名化（用于学习循环）
- 用户数据导出和删除

**审计和监控**
- 操作日志记录
- 异常行为检测
- 安全事件告警

**备份和恢复**
- 自动备份（每日/每周）
- 增量备份
- 一键恢复
